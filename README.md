# -Sistema-de-Gest-o-de-Vendas-pt-1
 Pequenos comerciantes costumam ter dificuldade em organizar seus pedidos, calcular valores corretamente, validar informações de clientes e manter um catálogo atualizado de produtos. Nesta primeira etapa, o objetivo é iniciar a criação de um sistema simples de gestão de vendas.Objetivo da Atividade Desenvolver as funcionalidades iniciais do sistema

# Sistema de Gestão de Vendas

## Descrição

Projeto desenvolvido em HTML, CSS e JavaScript para auxiliar pequenos comerciantes.

## Funcionalidades

- Catálogo de produtos.
- Calculadora de desconto.
- Consulta de CEP utilizando a API ViaCEP.
- Exibição dos produtos na página.

## Como executar

1. Abra a pasta no Visual Studio Code.
2. Instale a extensão *Live Server*.
3. Clique com o botão direito em index.html.
4. Selecione *Open with Live Server*.
